# Studio Yun — Graphic Design Portfolio

A responsive graphic design portfolio built with **HTML, CSS, JavaScript, and Bootstrap 5**.

## Run locally
1. Extract the ZIP file.
2. Open the `graphic-design-portfolio` folder in VS Code.
3. Open `index.html` in your browser. For a better development workflow, use the VS Code **Live Server** extension.

Bootstrap, Bootstrap Icons, Google Fonts, and the sample project photography load from CDNs, so an internet connection is required for those assets.

## Customize before publishing
- **Name / logo:** Search for `YUN` and `YUN STUDIO` in `index.html`.
- **Email:** Replace `hello@yourportfolio.com` with your real contact email.
- **Social links:** Replace the example Behance, Instagram, and LinkedIn URLs with your profiles.
- **Projects:** Replace the six concept projects, descriptions, categories, and image URLs with your own work. Project buttons use `data-title`, `data-category`, `data-description`, and `data-image` attributes for the detail modal.
- **About / services:** Edit the text to match your actual skills and services.
- **Colors and typography:** Edit the CSS variables at the top of `css/style.css`.

## Features
- Responsive Bootstrap navigation
- Project category filters (All, Branding, Posters, Digital)
- Click-to-open project detail modal
- Scroll reveal animation
- Mobile navigation closes after selecting a section
- Reduced-motion preference support
- Accessible image alt text and keyboard focus styles
